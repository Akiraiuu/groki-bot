# 有界语音故障定位（离线候选，尚未构建或安装）

现有状态把连接、收音、上传及对话事件等故障都归为error，关闭后无法区分来源。此改动提供固定分类以便后续定位，不改变会话终止策略。

/api/voice-test新增fault_source和fault_detail。fault_source仅取固件中的固定枚举标签；fault_detail仅在conversation_event时是ConversationError枚举0..7，其余为-1。映射：0未连接、1传输初始化、2发送失败、3协议、4服务端、5超时、6状态无效、7内存不足。这是错误类别，不能区分同一类别中的每个底层错误。

分类覆盖：连接、恢复、音频上传、麦克风、本地资源释放、输入轮次重置、异常回复和对话错误事件。首个终止故障在STOP和finish后保留；新的明确授权会话开始时清空。不保存原始错误字符串、音频、转写、回复、令牌或内部产品文本；不写入NVS。

不会改变授权、默认关闭、自动重连限制、3轮／60秒／等待10秒边界。旧API字段保留。未增加任何联网或测试入口。

主机回归新增：首因保留、关闭后权限失效、新授权清空、非错误停止不造故障、错误码范围过滤、异常回复和不可用分类。源码尚未编译；需要按精确文件清单上传原草稿分支后做主机及C152构建，安装和实测另行确认。
