# 精通AI助手：本地唤醒与单轮费用确认

显示名称为“精通AI助手”，本地目标短语为“你好，精通”。云端名字、
人设、声音和产品知识使用同一个已发布的 Saved Agent，不在固件写死知识。

## 当前实现边界

- StopWatch 配置编译 ESP-SR MultiNet5 中文模型及完整 model 镜像。
  这是实验性的离线命令短语识别，不是定制训练的 WakeNet 唤醒模型。
  使用 16kHz 单声道、完整拼音 ni hao jing tong、置信度门槛0.90；
  普通“你好”、“精通”和“介绍一下自己”是排除命令，不触发弹窗。
  目前直接使用麦克风PCM；不是官方推荐的 AFE+WakeNet 产品级组合。
  噪声/远场、误唤醒率和漏唤醒率均需要本地实机验证，不作准确率承诺。
- 开机默认关闭本地收音。设备“对话”页可开启本地唤醒，只在RAM保留。
  此开关本身不申请令牌、不连接云端、不上传录音。
- 本地命中只显示20秒费用确认，显示后麦克风停止，模型释放。
  屏幕明确说明 xAI、现场一句产品问题、1轮最多60秒、自动工具可能另计费。
  只有点击已经画出的“同意本次费用”按钮才调用既有单轮许可入口。
  超时、取消、黄键关闭、不同的批准nonce及旧弹窗点击均不授权连接。
- 回复完成、超时、出错或停止后断开且不重试。本地唤醒也关闭，
  不在本轮结束后偷偷重新收音；下次使用须重新在对话页开启。
- 本地诊断、云端收音/播放、本地识别由同一个 coordinator 串行拥有I2S。
  启动诊断或云端前必须关闭识别并擦除PCM/释放模型。模型缺失或资源
  申请失败时关闭此功能，保留已有手动语音入口。

## 安装与验证

现有分区表已经预留 model:0xdb0000/0x240000，布局不变；需要写入真实
mn5q8_cn模型。仅应用OTA不能补齐旧设备的空模型分区。安装前应比较设备
现有分区表，保留NVS/storage/otadata；通过USB分别写模型和应用并校验。
不得为了安装而整片擦除。离线编译和主机测试不代表已安装或识别通过。

主机测试覆盖识别不授权、未绘制/旧弹窗、20秒边界、取消、其他入口
抢占、两次并发点击、设备停止导致nonce过期以及60秒单轮截止。

实机安装、免费本地收音测试均需先以对话框确认就绪。免费唤醒检查只
观察弹窗，不点付费确认；完成后关闭本地唤醒。真实xAI测试另行逐轮确认。
编译过程中不调用xAI，不读取或上传凭证、产品册、用户录音或硬件结果。
