# StopWatch 单轮付费测试控制 v0.1

新固件默认离线，不因保存了设备口令、开机、OTA 或 Wi-Fi 恢复而连接 xAI。对话总开关及运行模式仍必须启用，但这两项只启动离线协调任务，不批准付费测试。

测试须由用户在本地设置页面点“确认费用并开始一轮测试”，再确认提示。本次范围为 xAI Agent、最多一轮回复、60 秒（包含连接等待），可能包含 Agent 已启用的搜索工具调用；这些工具可产生额外费用。一轮不是“恰好一个计费请求”，本机制没有金额硬上限，不能据此承诺固定费用。

- 未确认、页面打开、状态轮询、保存设置和重启均不会请求云端令牌或打开语音连接。
- 许可只存在 RAM，重启即失效。开始请求必须带明确同意、固定轮数/时限和当前 approval_id；重复请求不能延长时限，停止会让旧启动请求失效。
- 每次只尝试连接一次；连接失败、Wi-Fi 中断、收到服务器错误或被其他音频占用均结束，不重试、不自动恢复。
- 收到非空语音识别结果后，继续按原节奏发送静音供 VAD 收尾，不上传第二段新收音。原始断句可能只是短暂噪声，不能据此关闭首段收音；空识别结果也不会关闭收音。
- 回复播放完立即关闭麦克风和 WebSocket；纯文字/空回复结束即关闭。用户可随时点“停止并结束会话”。
- 60 秒到期后拒绝新的音频入队与网络写入，主任务关闭连接。此前已进入网络栈的写入及传输销毁仍可能需要短暂收尾，不是严格的账单金额上限。
- 每次客户端还绑定当轮 approval_id，旧传输不能借用下一次许可。

本地 HTTP：GET /api/voice-test 仅查询状态；POST 使用 application/json。开始体必须包含 op=start、confirm_paid=true、max_rounds=1、max_seconds=60 以及状态返回的 approval_id；停止体为 {"op":"stop"}。不要绕过用户确认脚本调用开始接口。

本轮只做源码、离线测试及固件编译；没有运行真实 xAI 测试，也不把编译成功当作实机音质或断开验证。安装应在不会启动旧版付费会话的下载模式下通过 USB 完成，再只观察新版默认离线状态；任何真实测试还需用户另行明确确认。
