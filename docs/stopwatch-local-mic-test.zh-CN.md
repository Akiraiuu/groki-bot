# 本地麦克风录音回放

用于区分收音失真、漏录与云端识别错误。默认不运行；需要用户明确准备好后才能启动。

- 设置页选择“本地录音回放（不联网）”，确认后只执行一次。
- 麦克风开启约 8 秒：先显示 3 秒预热倒计时，再显示“请说话”，保留后续 5 秒。
- 自动回放最后 5 秒，然后关闭麦克风和扬声器，清除录音缓冲区。
- 录音只在设备内存中，不写文件、不上传、不调用令牌服务或 xAI。
- 总时限 15 秒，取消、超时、播放或录音错误均停止，不重试。
- 与付费测试共用互斥状态，但本地许可不能通过任何付费网络发送检查。

本地控制使用原有 `/api/voice-test`，先 GET 获取当前 `approval_id`，再 POST：

```json
{"op":"record_local","confirm_local_recording":true,"record_seconds":5,"approval_id":123}
```

示例中的编号必须替换为当前编号。重复、过期请求及同时启动的其他测试会被拒绝。
停止使用 `{"op":"stop"}`。页面加载、轮询、启动失败和设备重启都不会自动启动。

在 Codex 协助下测试时，仍必须先通过选项对话框等待用户确认准备好。此功能的确认
不授权任何付费测试。若之后需要 xAI 测试，必须重新说明费用、轮数和时限并单独获准。
