# StopWatch：受控多轮对话、10秒等待退出及结束短句

## 会话范围

保留旧 start 命令的一问一答行为。新增明确授权入口：
{"op":"start_dialogue","confirm_paid":true,"max_rounds":3,"max_seconds":60,"idle_timeout_seconds":10,"approval_id":当前授权标识}

所有字段必须精确匹配；缺项、重复字段、错误上限或附加未支持字段均拒绝。Local 录放不能选择多轮配置。

本地唤醒检测后仅提供费用确认页；页面显示最多3轮、整次60秒、等待用户10秒无语音退出、自动工具可能额外收费。只有对当前已绘制页面的明确同意，才交换所显示范围的单次权限。开机、OTA、恢复 Wi-Fi、保存配置不会授予权限。

本改动不启用常驻麦克风：本地唤醒仍须先手动开启现有最多40秒监听。

## 等待与结束

整次60秒从费用确认／START开始，包含排队、连接、输入和回复；换轮不重新计时、不获取新令牌、不新建连接。最多3轮是一道额外上限，不保证60秒内能完成3轮。

10秒等待从当前轮实际 input_ready 开始，重复就绪更新不会延长。检测到用户说话／收到有效最终转写后暂停空闲等待，用户说话、云端处理及助手播放不计为空闲。下一轮麦克风预热就绪后重新开始10秒等待；总60秒始终有效。VAD/转写异常仍受总时限约束。

有效最终转写为完整结束短句时立即关闭，而不是等助手再生成一段道别回复：
再见、再见了、拜拜、拜拜了、退下吧、不用了、不需要了、结束对话、停止对话、结束聊天、谢谢再见、不用了谢谢；兼容 bye/byebye/goodbye。

仅忽略空白、标点及英文大小写后作整句匹配。“再见的意思是什么”“不用了但是请继续”等不会因含关键词而误停。

结束词依赖收音和语音识别，不是播放中的离线打断：当前设备使用半双工，助手播放时麦克风关闭，期间使用现有停止按钮。

达到第三轮、10秒无用户语音、结束短句、总时限、取消、错误或中断后，都撤销输入权限并走统一资源清理，不自动重连。

## 换轮音频安全

最终转写后继续关闭当前音频输入。只有已授权多轮配置、当前权限有效、上一回复已完成且播放排空后才允许 begin_input_turn。

换轮在发送互斥锁下提高音频 epoch、释放旧排队PCM，再开启输入。每个音频块携带 epoch，发送前和真正写出前均检查；已经被发送任务取出但尚未写出的旧音频也不能在下一轮复活。

单轮配置、缺失权限、停止／过期会话、回复未完成、重复重新开启均拒绝。

## 观测与验证

/api/voice-test 返回真实 max_rounds、completed_rounds、idle_timeout_ms、idle_remaining_ms，保留 input_ready 及会话 nonce。新增结束原因 idle_timeout、farewell、round_limit；旧字段语义保留。

回归用例覆盖首次/再次等待、精确10秒、重复ready、助手工作不触发空闲、总时限不延长、三轮上限、旧nonce隔离、严格新命令、结束短句误匹配、确认范围绑定和同会话换轮排队音频清理。

当前为本地源码准备阶段；C++ 主机回归及 C152 编译尚未运行，本说明不是实机验收。源码上传/构建、设备更新和实际付费测试按各自授权范围处理。
