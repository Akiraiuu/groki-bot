# 菜单关闭后的文字气泡计时

设置菜单覆盖头像时，头像渲染循环暂停，DrawContext.now_ms停在旧头像帧。若新消息在菜单期间到达，旧set_balloon_text使用这个旧时间作为起点；返回头像后第一帧的当前时间已经远超hold，可能立即标记完成，导致文字气泡闪现后消失。

改为排队新消息时设置start_pending，真正调用气泡渲染的第一帧才记录当前now_ms。短文字从首次显示起保留完整hold；长文字从首次显示起跑完整滚动周期。替换消息重新开始计时，清除消息同时清除pending。保持原有默认显示时长和完成回调含义。

主机回归直接编译生产balloon.cpp，仅绘图/字体边界使用替身。覆盖长时间菜单停留、完成后替换、长文滚动、32位时钟回绕、空文本和绘图分组/裁剪配对。

此修复只影响文字气泡显示；不改变本地唤醒判定、麦克风、时限、停止和费用确认，不连接任何云端。不能把显示恢复等同于唤醒语识别通过。实机显示验证前仍需明确就绪确认。
