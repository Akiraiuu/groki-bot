# StopWatch 固定正视

此版本默认开启固定正视，已有配置在升级后缺少该键时也默认开启。
眼睛在白色头像内左右对称、保持正视；触摸、倾斜、随机扫视、周期绕圈和
表情预设中内置的侧看偏移均不再改变眼睛中心。保留表情轮廓变化、眨眼、
呼吸和嘴部动画。关闭后恢复原有自然视线；不修改舵机控制。

- 设备：黄色按键打开菜单 → 设置2 → 固定正视。
- 网页：设备当前 IP → アバター（头像）→ 视线设置 → 固定正视。
- 两处均即时生效并单独保存，重启后保留，无需点击保存并重启。
- 切换头像预设或恢复默认头像不会清除此选项。
- `fixed-gaze` 注册为 Immediate 布尔设置，NVS 键为 `fixed_gaze`。
- `POST /api/fixed-gaze` 接受纯文本 `1` / `0`，沿用网页认证。
- 本功能不录音、不申请令牌、不连接 xAI，也不会启动付费会话。

离线验证覆盖全部表情、过渡混合、多个动画时刻、眨眼保留与开关恢复。
圆屏修正：眼型数据使用 320×240 设计坐标，VM 必须按实际屏幕尺寸和圆屏
缩放换算后绘制；补充 466×466 圆屏等四种尺寸下的实际 VM 绘制检查，验证
眼睛与脸使用同一坐标系，并位于白色脸部内。
实际设备显示效果仍需安装后的用户确认；此说明不代表已完成实机验证。
